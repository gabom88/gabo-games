# Gabo Games

Catálogo con estilo pixel retro de mis juegos y apps hechos en JavaScript.
Cada tarjeta enlaza a la versión Live del proyecto y a su repositorio.

| Juego | Live | Repo |
|---|---|---|
| GBoy-JS | https://gboy-js.web.app/ | [gemuboy-js](https://github.com/gabom88/gemuboy-js) |
| Mario & Luigi | https://gabom88.github.io/mario-luigi-js/ | [mario-luigi-js](https://github.com/gabom88/mario-luigi-js) |
| Digger JS | https://gabom88.github.io/digger-js/ | [digger-js](https://github.com/gabom88/digger-js) |
| Paint 98 | https://gabom88.github.io/Paint-98/ | [Paint-98](https://github.com/gabom88/Paint-98) |
| かな Kana | https://gabom88.github.io/hiragana/ | [hiragana](https://github.com/gabom88/hiragana) |

Las capturas se cargan directamente desde cada repositorio (`raw.githubusercontent.com`).
La de Kana (`img/hiragana.png`) se tomó de la app, porque su repo no incluye capturas.
En los cartuchos de Mario & Luigi y Digger, al pasar el ratón por la captura se ve el GIF animado.

Es un sitio estático (HTML + CSS + JS, sin compilación). Para publicarlo, activa
**GitHub Pages** en *Settings → Pages* y elige esta rama y la carpeta raíz.
